## 🎯 Exam Day Tips

### **Before Exam**
- Get plenty of sleep night before (not 4am cram session)
- Review "Common Mistakes" sections one more time
- Review "Quick Reference" commands
- Don't read new material morning of exam

### **During Exam**
- Read each question carefully (scenario-based)
- Eliminate obviously wrong answers first
- Look for keywords (must, should, can, cannot)
- Mark uncertain questions, come back later
- Manage time: ~1.5 minutes per question average

### **Exam Question Patterns**

**Pattern 1: "Which service should you use?"**
- Look for comparison in guides
- Consider scale, consistency, cost
- Example: "Which database for 100k ops/sec?" → Bigtable

**Pattern 2: "How do you configure X?"**
- Look for step-by-step setup in guides
- Terraform examples usually match what exam wants
- Example: "Set up alert for high CPU" → follows metric, threshold, duration, channel

**Pattern 3: "What's the security issue?"**
- Look for "Security best practices" section
- Common issues: default service account, storing keys in code, no rotation
- Example: "What's wrong with this?" → Service account has Owner role (too permissive)

**Pattern 4: "Which would improve performance/cost?"**
- Look at trade-offs in decision trees
- Example: "Reduce bill by 20%?" → Use commitment discounts, right-size, delete idle
